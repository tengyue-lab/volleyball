## 1. Leaderboard — Rank Information Icon

On the Leaderboard page, add a small information icon (ⓘ) near the Leaderboard heading.

When clicked, open a clean modal popup titled:

**Competitive Ranks**

The popup should show every competitive tier and its corresponding ELO range.

Tiers:
- Iron
- Bronze
- Silver
- Gold
- Platinum
- Diamond
- Masters

Requirements:
- Read the actual ELO thresholds from the application's existing tier configuration.
- Do not invent or modify tier thresholds.
- Display the minimum and maximum ELO values for each tier, where applicable.
- Masters should show its actual configured minimum and any upper-bound behavior.
- Use a simple two-column layout: Rank | ELO Range.
- Make the popup responsive on mobile.
- Allow closing via an X button, tapping outside or pressing Escape.
- Use accessible modal behavior and keyboard focus management.
- Keep the main leaderboard layout unchanged.

The information icon should be subtle and not take up too much space.

## 2. Profile — Display Rank and ELO Side by Side

In the Profile tab, display the player's competitive Rank and exact numeric ELO next to each other.

Suggested layout:

[ Rank: Gold ⓘ ]    [ ELO: 1245 ]

Use two clean, evenly spaced cards or columns.

Requirements:
- Show the player's actual current competitive tier.
- Show their actual current numeric ELO.
- Add the same information icon beside the Rank label.
- Clicking it should open the same Competitive Ranks popup used on the Leaderboard page.
- Reuse a shared modal component rather than duplicating its implementation.
- Ensure the two cards display neatly on mobile.

IMPORTANT:
The exact ELO number should be visible only to the authenticated player viewing their own Profile and to appropriately authorized admins.

Do not expose other players' private ELO ratings through public leaderboard data or APIs.

Preserve the existing provisional-player behavior. If provisional players do not yet have an official competitive tier, display the correct provisional state rather than inventing a rank.
